## 1. Automatic Dependency Injection

### The Problem

Traditional Go applications require manual dependency wiring:

```go
// Manual wiring - painful as app grows
func main() {
    config := LoadConfig()
    logger := NewLogger(config)
    db := NewDatabase(config, logger)
    cache := NewRedis(config)

    userRepo := NewUserRepository(db, logger)
    postRepo := NewPostRepository(db, logger)

    userService := NewUserService(userRepo, cache, logger)
    postService := NewPostService(postRepo, userService, cache, logger)

    userController := NewUserController(userService, logger)
    postController := NewPostController(postService, userService, logger)

    // ... register routes manually
}
```

### GIMBAP Solution

Declare what you need in constructors:

```go
// Just define your constructor parameters
func NewUserService(repo *UserRepository, cache *Redis, logger *Logger) *UserService {
    return &UserService{
        Repo:   repo,
        Cache:  cache,
        Logger: logger,
    }
}

// GIMBAP automatically:
// 1. Detects dependencies
// 2. Resolves order
// 3. Instantiates everything
// 4. Injects instances
```

<Callout type="success">
**Zero configuration needed** - GIMBAP uses Go's type system to automatically wire everything!
</Callout>

### Advanced DI Features

- **Circular Dependency Detection**: Catches impossible dependency graphs at startup
- **Missing Dependency Detection**: Clear error messages for unregistered providers
- **Singleton by Default**: All instances are created once and reused
- **Graph Visualization**: Debug dependency relationships easily
- **Order Guarantee**: Dependencies always instantiate before dependents

## 2. Module System

### Organize by Features

```go
// User Module - self-contained
var UserModule = gimbap.DefineModule(gimbap.ModuleOption{
    Name: "UserModule",
    Providers: []*gimbap.Provider{
        UserServiceProvider,
        UserRepositoryProvider,
    },
    Controllers: []*gimbap.Controller{
        UserControllerProvider,
    },
})

// Compose modules hierarchically
var AppModule = gimbap.DefineModule(gimbap.ModuleOption{
    Name: "AppModule",
    SubModules: []*gimbap.Module{
        UserModule,
        AuthModule,
        PaymentModule,
    },
})
```

### Module Benefits

- **Encapsulation**: Module internals are hidden
- **Reusability**: Share modules across projects
- **Testing**: Test modules in isolation
- **Scalability**: Add features without touching core
- **Team Collaboration**: Different teams own different modules

## 3. Pluggable HTTP Engines

### Switch Engines Without Code Changes

```go
// Use Gin
app := gimbap.CreateApp(gimbap.AppOption{
    ServerEngine: gin_engine.NewGinHttpEngine(),
})

// Switch to Fiber - same controller code!
app := gimbap.CreateApp(gimbap.AppOption{
    ServerEngine: fiber_engine.NewFiberHttpEngine(),
})

// Or Echo
app := gimbap.CreateApp(gimbap.AppOption{
    ServerEngine: echo_engine.NewEchoHttpEngine(),
})
```

<Callout type="warning">
**Note**: Handlers must match the engine type (Gin handlers for Gin engine, etc.). Future versions will include adapter layers for compatibility.
</Callout>

### Supported Engines

| Engine | Performance | Features | Best For |
|--------|-------------|----------|----------|
| **Gin** | Fast | Mature, widely used | General purpose |
| **Fiber** | Fastest | Express-like API | High performance |
| **Echo** | Fast | Minimalist, clean | Simple APIs |
| **Custom** | Varies | Full control | Special requirements |

## 4. Controller Pattern

### Clean MVC Architecture

```go
type UserController struct {
    UserService *UserService
}

// Define routes declaratively
func (c *UserController) GetRouteSpecs() []gimbap.RouteSpec {
    return []gimbap.RouteSpec{
        {Method: "GET", Path: "/users", Handler: c.List},
        {Method: "POST", Path: "/users", Handler: c.Create},
        {Method: "GET", Path: "/users/:id", Handler: c.Get},
        {Method: "PUT", Path: "/users/:id", Handler: c.Update},
        {Method: "DELETE", Path: "/users/:id", Handler: c.Delete},
    }
}

// Handlers automatically registered
func (c *UserController) List(ctx *gin.Context) {
    users := c.UserService.FindAll()
    ctx.JSON(200, users)
}
```

### Controller Features

- **Auto Route Registration**: No manual gin.GET() calls
- **Dependency Injection**: Services injected automatically
- **Root Path Support**: Group routes under common prefix
- **Type Safety**: Compile-time checked handlers
- **Testability**: Easy to unit test controllers

## 5. Microservices Support

Run multiple services in one app:

```go
type GRPCServer struct {
    UserService *UserService
}

func (g *GRPCServer) Start() {
    // Start gRPC server
}

func (g *GRPCServer) Stop() {
    // Graceful shutdown
}

// Add to app
app.AddMicroServices(
    gimbap.DefineMicroService(gimbap.MicroServiceProviderOption{
        Name: "GRPCServer",
        Instantiator: NewGRPCServer,
    }),
)
```

### Unified Lifecycle

- All services start/stop together
- Graceful shutdown for all
- Shared dependency injection
- Coordinated lifecycle hooks

## 6. Type Safety

### Compile-Time Guarantees

```go
// Type-safe provider retrieval
userService := gimbap.GetProvider(app, UserService{})
// Type: *UserService - fully checked!

// Type-safe dependency injection
func NewUserController(
    service *UserService,  // Must be registered
    logger *Logger,        // Must be registered
) *UserController {
    // Compiler ensures types match
}
```

### No Magic Strings

- No string-based lookups
- No runtime type assertions (after DI)
- No reflection in hot path
- Full IDE autocomplete support

## 7. Production Features

### Graceful Shutdown

```go
// Automatic signal handling
// SIGTERM, SIGINT → graceful shutdown
```

Shutdown sequence:
1. Stop accepting new requests
2. Wait for active requests (max 5s)
3. Call `onStop` lifecycle hooks
4. Stop microservices (max 5s each)
5. Clean exit

### Lifecycle Hooks

```go
app.AddOnStartListener(func() {
    // Initialize resources
    // Warm caches
    // Connect to services
})

app.AddOnStopListener(func() {
    // Close connections
    // Flush buffers
    // Cleanup resources
})
```

### Observability

```go
// Custom logger support
app.SetCustomLogger(myLogger)

// Structured logging built-in
logger.Logf("User created: id=%s", userID)
logger.Errorf("Database error: %v", err)
logger.Warnf("Slow query: %dms", duration)
```

## 8. Testing Support

### Easy Mocking

```go
// Create test module with mocks
testModule := gimbap.DefineModule(gimbap.ModuleOption{
    Name: "TestModule",
    Providers: []*gimbap.Provider{
        // Real service
        RealServiceProvider,
        // Mock database
        MockDatabaseProvider,
    },
})

// Test with mocked dependencies
app := gimbap.CreateApp(gimbap.AppOption{
    AppModule: testModule,
    ServerEngine: engine.NewNullEngine(), // No HTTP server
})
```

### Isolation

- Test providers in isolation
- Mock external dependencies
- Integration test full modules
- E2E test entire app

### Benchmarks

```
After startup, GIMBAP adds:
├─ Request Handling: 0ns overhead (native engine)
├─ Controller Dispatch: ~10ns (function call)
└─ Dependency Access: 0ns (direct reference)

Startup overhead:
├─ Small app (< 20 providers): < 1ms
├─ Medium app (50-100 providers): 1-5ms
└─ Large app (200+ providers): 5-20ms
```
