# GIMBAP Framework Guide for Software Engineers

## Overview

GIMBAP (Go Injection Management for Better Application Programming) is a Go web framework that brings Spring Boot and NestJS-like dependency injection patterns to Go. It provides automatic dependency injection, modular architecture, and flexible HTTP server engine support.

## Important Guidelines for Working with GIMBAP

### 1. Always Use Mermaid Diagrams
When explaining GIMBAP concepts, **eagerly create Mermaid diagrams** to visualize:
- Module dependency graphs
- Provider relationships
- Application architecture
- Request flow through controllers

### 2. Always Check Go Types Carefully
**Critical**: Go's type system differs from Java/TypeScript. Always verify:
- Pointer types (`*Type`) vs value types (`Type`)
- Interface satisfaction
- Constructor return types must match provider expectations
- Method receivers (pointer vs value)

### 3. Provide Extensive Code Examples
Never explain concepts without accompanying code snippets. Show complete, working examples.

## Core Concepts Comparison

### Spring Boot / NestJS → GIMBAP Mapping

| Spring Boot | NestJS | GIMBAP | Description |
|-------------|---------|---------|-------------|
| `@Component/@Service` | `@Injectable()` | `Provider` | Injectable service/component |
| `@RestController` | `@Controller()` | `Controller` | HTTP endpoint handler |
| `@Configuration` | `@Module()` | `Module` | Dependency container |
| `@Autowired` | Constructor injection | Constructor params | Dependency injection |
| `@SpringBootApplication` | `NestFactory.create()` | `gimbap.CreateApp()` | Application bootstrap |
| `@Bean` | Provider definition | `DefineProvider()` | Bean/provider definition |
| `@RequestMapping` | `@Get()/@Post()` | `GetRouteSpecs()` | Route definition |

## 1. Providers (Services)

### Spring Boot Example
```java
@Service
public class UserService {
    private final DatabaseService dbService;
    
    @Autowired
    public UserService(DatabaseService dbService) {
        this.dbService = dbService;
    }
    
    public User getUser(Long id) {
        return dbService.findById(id);
    }
}
```

### NestJS Example
```typescript
@Injectable()
export class UserService {
    constructor(private readonly dbService: DatabaseService) {}
    
    async getUser(id: number): Promise<User> {
        return this.dbService.findById(id);
    }
}
```

### GIMBAP Example
```go
package user

import "github.com/jhseong7/gimbap"

// Define the service struct
type UserService struct {
    dbService *DatabaseService  // Note: Pointer type!
}

// Constructor function - parameters are injected automatically
func NewUserService(dbService *DatabaseService) *UserService {
    return &UserService{
        dbService: dbService,
    }
}

// Service methods
func (s *UserService) GetUser(id int64) (*User, error) {
    return s.dbService.FindById(id)
}

// Define the provider
var UserServiceProvider = gimbap.DefineProvider(gimbap.ProviderOption{
    Name:         "UserService",
    Instantiator: NewUserService,  // Pass the constructor function
})
```

## 2. Controllers

### Spring Boot Example
```java
@RestController
@RequestMapping("/users")
public class UserController {
    @Autowired
    private UserService userService;
    
    @GetMapping("/{id}")
    public User getUser(@PathVariable Long id) {
        return userService.getUser(id);
    }
    
    @PostMapping
    public User createUser(@RequestBody User user) {
        return userService.createUser(user);
    }
}
```

### NestJS Example
```typescript
@Controller('users')
export class UserController {
    constructor(private readonly userService: UserService) {}
    
    @Get(':id')
    async getUser(@Param('id') id: string): Promise<User> {
        return this.userService.getUser(+id);
    }
    
    @Post()
    async createUser(@Body() user: User): Promise<User> {
        return this.userService.createUser(user);
    }
}
```

### GIMBAP Example (Gin Engine)
```go
package user

import (
    "github.com/gin-gonic/gin"
    "github.com/jhseong7/gimbap"
)

// Controller struct implementing IController interface
type UserController struct {
    gimbap.IController
    userService *UserService  // Injected dependency
}

// Constructor for dependency injection
func NewUserController(userService *UserService) *UserController {
    return &UserController{
        userService: userService,
    }
}

// IMPORTANT: This method defines all routes for the controller
func (c *UserController) GetRouteSpecs() []gimbap.RouteSpec {
    return []gimbap.RouteSpec{
        {Method: "GET", Path: "/:id", Handler: c.GetUser},
        {Method: "POST", Path: "/", Handler: c.CreateUser},
    }
}

// Handler methods - Note: Gin-specific context type
func (c *UserController) GetUser(ctx *gin.Context) {
    id := ctx.Param("id")
    user, err := c.userService.GetUser(id)
    if err != nil {
        ctx.JSON(500, gin.H{"error": err.Error()})
        return
    }
    ctx.JSON(200, user)
}

func (c *UserController) CreateUser(ctx *gin.Context) {
    var user User
    if err := ctx.ShouldBindJSON(&user); err != nil {
        ctx.JSON(400, gin.H{"error": err.Error()})
        return
    }
    created, err := c.userService.CreateUser(&user)
    if err != nil {
        ctx.JSON(500, gin.H{"error": err.Error()})
        return
    }
    ctx.JSON(201, created)
}

// Define the controller provider
var UserControllerProvider = gimbap.DefineController(gimbap.ControllerOption{
    Name:         "UserController",
    Instantiator: NewUserController,
    RootPath:     "users",  // Base path for all routes
})
```

### Multi-Engine Support
GIMBAP supports multiple HTTP engines. Here's the same controller for Fiber:

```go
// Fiber version - Note the different context type and error returns
func (c *UserController) GetUserFiber(ctx *fiber.Ctx) error {
    id := ctx.Params("id")
    user, err := c.userService.GetUser(id)
    if err != nil {
        return ctx.Status(500).JSON(fiber.Map{"error": err.Error()})
    }
    return ctx.JSON(user)
}
```

### GIMBAP Example
```go
package user

import "github.com/jhseong7/gimbap"

// Define a module that groups related providers and controllers
var UserModule = gimbap.DefineModule(gimbap.ModuleOption{
    Name: "UserModule",
    Providers: []*gimbap.Provider{
        UserServiceProvider,
        UserRepositoryProvider,
    },
    Controllers: []*gimbap.Controller{
        UserControllerProvider,
    },
})

// Modules can depend on other modules
var AppModule = gimbap.DefineModule(gimbap.ModuleOption{
    Name: "AppModule",
    SubModules: []*gimbap.Module{
        UserModule,
        DatabaseModule,
        AuthModule,
    },
})
```

```go
package main

import (
    "github.com/jhseong7/gimbap"
    "github.com/jhseong7/gimbap/engine/gin"
    "myapp/modules"
)

func main() {
    // Create app with root module and server engine
    app := gimbap.CreateApp(gimbap.AppOption{
        AppName:      "MyApp",
        AppModule:    modules.AppModule,
        ServerEngine: gin_engine.NewGinHttpEngine(), // Can swap to Fiber/Echo
    })
    
    // Add middleware (engine-specific)
    app.AddMiddleware(func(ctx *gin.Context) {
        ctx.Header("X-Custom-Header", "value")
        ctx.Next()
    })
    
    // Run with default options (port 8080)
    app.Run()
    
    // Or run with custom options
    app.RunWithOptions(gimbap.RuntimeOptions{
        Port: 3000,
        TLS: &gimbap.TLSOption{
            CertFile: "cert.pem",
            KeyFile:  "key.pem",
        },
    })
}
```

## 6. Microservices

GIMBAP supports background services similar to NestJS providers that implement lifecycle hooks.

### NestJS Example
```typescript
@Injectable()
export class TaskService implements OnModuleInit, OnModuleDestroy {
    onModuleInit() {
        console.log('Starting background tasks...');
    }
    
    onModuleDestroy() {
        console.log('Cleanup...');
    }
}
```

### GIMBAP Example
```go
package services

import (
    "time"
    "github.com/jhseong7/gimbap/microservice"
)

type TaskService struct {
    microservice.IMicroService
    logger *LoggerService
    config *Config
}

// Start is called when the app starts
func (s *TaskService) Start() {
    s.logger.Log("Starting background tasks...")
    go s.runPeriodicTask()
}

// Stop is called on app shutdown
func (s *TaskService) Stop() {
    s.logger.Log("Stopping background tasks...")
}

func (s *TaskService) runPeriodicTask() {
    ticker := time.NewTicker(5 * time.Second)
    for range ticker.C {
        s.logger.Log("Running periodic task...")
    }
}

// Constructor with DI
func NewTaskService(logger *LoggerService, config *Config) *TaskService {
    return &TaskService{
        logger: logger,
        config: config,
    }
}

// Define as microservice provider
var TaskServiceProvider = microservice.DefineMicroService(
    microservice.MicroServiceProviderOption{
        Name:         "TaskService",
        Instantiator: NewTaskService,
    },
)

// In main.go
app.AddMicroServices(TaskServiceProvider)
```

## Key Differences from Spring/NestJS

### 1. No Annotations/Decorators
Go doesn't support annotations, so GIMBAP uses explicit provider definitions:
- Spring: `@Service`, `@Autowired`
- NestJS: `@Injectable()`, `@Controller()`
- GIMBAP: `DefineProvider()`, `DefineController()`

### 2. Explicit Type Registration
You must explicitly register all providers with `DefineProvider()`:
```go
// This won't work - no auto-discovery
type MyService struct {}

// Must explicitly register
var MyServiceProvider = gimbap.DefineProvider(gimbap.ProviderOption{
    Name:         "MyService",
    Instantiator: NewMyService,
})
```

### 3. Pointer vs Value Types
**Critical**: Always check whether to use pointer or value types:
```go
// Constructor returns pointer
func NewService() *Service { return &Service{} }

// Dependency injection uses pointer
func NewController(svc *Service) *Controller {
    return &Controller{service: svc}
}

// Struct field stores value (copies the service)
type Controller struct {
    service Service  // ❌ Wrong - loses reference
}

// Correct - store as pointer
type Controller struct {
    service *Service  // ✅ Correct
}
```

### 4. Engine-Specific Handlers
Controller handlers must match the HTTP engine's signature:
- Gin: `func(c *gin.Context)`
- Fiber: `func(c *fiber.Ctx) error`
- Echo: `func(c echo.Context) error`

### 5. No Automatic Route Parameter Binding
You must manually extract parameters:
```go
// Spring/NestJS handle this automatically
// GIMBAP requires manual extraction
func (c *Controller) GetUser(ctx *gin.Context) {
    id := ctx.Param("id")  // Manual extraction
    // Convert string to int, handle errors, etc.
}
```

- [ ] Constructor returns pointer type (`*Type`)
- [ ] Dependencies are pointer types in struct fields
- [ ] Constructor parameters match injected types exactly
- [ ] Handler signatures match the chosen engine
- [ ] Interface implementations are checked

## Common Patterns

### 1. Repository Pattern
```go
type UserRepository interface {
    FindById(id int64) (*User, error)
    Save(user *User) error
}

type userRepositoryImpl struct {
    db *DatabaseService
}

func NewUserRepository(db *DatabaseService) UserRepository {
    return &userRepositoryImpl{db: db}
}

// Service depends on interface, not implementation
type UserService struct {
    repo UserRepository  // Interface type
}
```

### 2. Configuration Injection
```go
type AppConfig struct {
    Port        int
    DatabaseURL string
    JWTSecret   string
}

func NewAppConfig() *AppConfig {
    return &AppConfig{
        Port:        getEnvInt("PORT", 8080),
        DatabaseURL: getEnv("DATABASE_URL", "localhost:5432"),
        JWTSecret:   getEnv("JWT_SECRET", "secret"),
    }
}

// Inject config into services
type AuthService struct {
    config *AppConfig
    // ... other deps
}
```

### 3. Middleware as Providers
```go
type AuthMiddleware struct {
    authService *AuthService
}

func NewAuthMiddleware(authService *AuthService) *AuthMiddleware {
    return &AuthMiddleware{authService: authService}
}

func (m *AuthMiddleware) Authenticate() gin.HandlerFunc {
    return func(c *gin.Context) {
        token := c.GetHeader("Authorization")
        if !m.authService.ValidateToken(token) {
            c.AbortWithStatus(401)
            return
        }
        c.Next()
    }
}

// In controller
func (c *UserController) GetRouteSpecs() []gimbap.RouteSpec {
    return []gimbap.RouteSpec{
        {
            Method:  "GET",
            Path:    "/profile",
            Handler: c.GetProfile,
            Middlewares: []gin.HandlerFunc{
                c.authMiddleware.Authenticate(),
            },
        },
    }
}
```

## Troubleshooting

### 1. Circular Dependencies
```mermaid
graph LR
    A[Service A] --> B[Service B]
    B --> A
    style A fill:#f99,stroke:#333,stroke-width:2px
    style B fill:#f99,stroke:#333,stroke-width:2px
```
Solution: Introduce interfaces or restructure dependencies

### 2. Type Mismatch Errors
Always check:
- Return type of constructor matches provider expectation
- Pointer vs value types in dependencies
- Interface satisfaction

### 3. Route Not Found
Verify:
- Controller is added to module
- Module is included in app
- `GetRouteSpecs()` returns correct routes
- Path includes controller's `RootPath`

## Summary

GIMBAP brings familiar DI patterns to Go with some adaptations for Go's type system. Remember:
1. Always visualize dependencies with diagrams
2. Check types carefully (especially pointers)
3. Provide complete code examples
4. Explicitly register all providers
5. Match handler signatures to chosen engine

This framework excels at creating modular, testable Go applications with clear separation of concerns, similar to Spring Boot and NestJS architectures.

## Core Decorators

### @Injectable() → Provider

#### NestJS
```typescript
@Injectable()
export class CatsService {
  private readonly cats: Cat[] = [];

  constructor(
    private readonly logger: LoggerService,
    @Inject('CONFIG') private readonly config: ConfigType
  ) {}

  create(cat: Cat) {
    this.cats.push(cat);
    this.logger.log('Cat created');
  }

  findAll(): Cat[] {
    return this.cats;
  }
}
```

#### GIMBAP
```go
package cats

import "github.com/jhseong7/gimbap"

type CatsService struct {
    cats   []Cat
    logger *LoggerService
    config *ConfigType
}

func NewCatsService(logger *LoggerService, config *ConfigType) *CatsService {
    return &CatsService{
        cats:   make([]Cat, 0),
        logger: logger,
        config: config,
    }
}

func (s *CatsService) Create(cat Cat) {
    s.cats = append(s.cats, cat)
    s.logger.Log("Cat created")
}

func (s *CatsService) FindAll() []Cat {
    return s.cats
}

var CatsServiceProvider = gimbap.DefineProvider(gimbap.ProviderOption{
    Name:         "CatsService",
    Instantiator: NewCatsService,
})
```

### @Controller() → Controller

#### NestJS
```typescript
@Controller('cats')
@UseGuards(AuthGuard)
@UseInterceptors(LoggingInterceptor)
export class CatsController {
  constructor(private readonly catsService: CatsService) {}

  @Post()
  @UsePipes(ValidationPipe)
  async create(@Body() createCatDto: CreateCatDto) {
    return this.catsService.create(createCatDto);
  }

  @Get()
  @UseGuards(RolesGuard)
  @Roles('admin')
  async findAll(@Query('limit') limit: number) {
    return this.catsService.findAll();
  }

  @Get(':id')
  async findOne(@Param('id', ParseIntPipe) id: number) {
    return this.catsService.findOne(id);
  }
}
```

#### GIMBAP (Gin Engine)
```go
package cats

import (
    "strconv"
    "github.com/gin-gonic/gin"
    "github.com/jhseong7/gimbap"
)

type CatsController struct {
    gimbap.IController
    catsService     *CatsService
    authGuard       *AuthGuard
    loggingInterceptor *LoggingInterceptor
    validationPipe  *ValidationPipe
    rolesGuard      *RolesGuard
}

func NewCatsController(
    catsService *CatsService,
    authGuard *AuthGuard,
    loggingInterceptor *LoggingInterceptor,
    validationPipe *ValidationPipe,
    rolesGuard *RolesGuard,
) *CatsController {
    return &CatsController{
        catsService:        catsService,
        authGuard:          authGuard,
        loggingInterceptor: loggingInterceptor,
        validationPipe:     validationPipe,
        rolesGuard:         rolesGuard,
    }
}

func (c *CatsController) GetRouteSpecs() []gimbap.RouteSpec {
    return []gimbap.RouteSpec{
        {
            Method:  "POST",
            Path:    "/",
            Handler: c.Create,
            Middlewares: []gin.HandlerFunc{
                c.authGuard.Authenticate(),
                c.loggingInterceptor.Intercept(),
                c.validationPipe.Validate(CreateCatDto{}),
            },
        },
        {
            Method:  "GET",
            Path:    "/",
            Handler: c.FindAll,
            Middlewares: []gin.HandlerFunc{
                c.authGuard.Authenticate(),
                c.rolesGuard.RequireRoles("admin"),
                c.loggingInterceptor.Intercept(),
            },
        },
        {
            Method:  "GET",
            Path:    "/:id",
            Handler: c.FindOne,
            Middlewares: []gin.HandlerFunc{
                c.authGuard.Authenticate(),
                c.loggingInterceptor.Intercept(),
            },
        },
    }
}

func (c *CatsController) Create(ctx *gin.Context) {
    var dto CreateCatDto
    if err := ctx.ShouldBindJSON(&dto); err != nil {
        ctx.JSON(400, gin.H{"error": err.Error()})
        return
    }

    cat := c.catsService.Create(dto)
    ctx.JSON(201, cat)
}

func (c *CatsController) FindAll(ctx *gin.Context) {
    limitStr := ctx.Query("limit")
    limit := 10 // default
    if limitStr != "" {
```

### Auth Guard

#### NestJS
```typescript
@Injectable()
export class AuthGuard implements CanActivate {
  constructor(private jwtService: JwtService) {}

  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest();
    const token = this.extractTokenFromHeader(request);
    
    if (!token) {
      throw new UnauthorizedException();
    }
    
    try {
      const payload = this.jwtService.verify(token);
      request.user = payload;
      return true;
    } catch {
      throw new UnauthorizedException();
    }
  }

  private extractTokenFromHeader(request: Request): string | undefined {
    const [type, token] = request.headers.authorization?.split(' ') ?? [];
    return type === 'Bearer' ? token : undefined;
  }
}
```

```go
func (g *AuthGuard) Authenticate() gin.HandlerFunc {
    return func(c *gin.Context) {
        token := g.extractTokenFromHeader(c)
        
        if token == "" {
            c.JSON(401, gin.H{"error": "Unauthorized"})
            c.Abort()
            return
        }
        
        payload, err := g.jwtService.Verify(token)
        if err != nil {
            c.JSON(401, gin.H{"error": "Invalid token"})

        // Store user in context

        c.Next()
    }

func (g *AuthGuard) extractTokenFromHeader(c *gin.Context) string {
    authHeader := c.GetHeader("Authorization")
    if authHeader == "" {
        return ""
    }
    
    parts := strings.Split(authHeader, " ")
    if len(parts) != 2 || parts[0] != "Bearer" {
        return ""
    }
    
    return parts[1]
}
```

```typescript
@Injectable()
export class RolesGuard implements CanActivate {
  constructor(private reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const requiredRoles = this.reflector.getAllAndOverride<Role[]>(ROLES_KEY, [
      context.getHandler(),
```

```go
}

func (i *TransformInterceptor) Transform() gin.HandlerFunc {
    return func(c *gin.Context) {
        // Capture the response
        writer := &responseWriter{ResponseWriter: c.Writer, body: []byte{}}
        c.Writer = writer
        
        c.Next()
        
        // Transform the response
        if c.Writer.Status() < 400 {
            var originalResponse interface{}
            if err := json.Unmarshal(writer.body, &originalResponse); err == nil {
                transformedResponse := map[string]interface{}{
                    "success":   true,
                    "data":      originalResponse,
                    "timestamp": time.Now().Format(time.RFC3339),
                }
                
                c.Writer = writer.ResponseWriter
                c.JSON(c.Writer.Status(), transformedResponse)
            }
        }
    }
}

type responseWriter struct {
    gin.ResponseWriter
    body []byte
}

func (w *responseWriter) Write(data []byte) (int, error) {
    w.body = append(w.body, data...)
    return len(data), nil
```

```go
type CorsMiddleware struct {
    config *CorsConfig
}

type CorsConfig struct {
    AllowOrigins     []string
    AllowMethods     []string
    AllowHeaders     []string
    AllowCredentials bool
}

func NewCorsMiddleware(config *CorsConfig) *CorsMiddleware {
    return &CorsMiddleware{config: config}
}

func (m *CorsMiddleware) Handle() gin.HandlerFunc {
    return func(c *gin.Context) {
        origin := c.Request.Header.Get("Origin")
        
        // Check if origin is allowed
        allowed := false
        for _, allowedOrigin := range m.config.AllowOrigins {
            if allowedOrigin == "*" || allowedOrigin == origin {
                allowed = true
                break
            }
        }
        
        if allowed {
            c.Header("Access-Control-Allow-Origin", origin)
            c.Header("Access-Control-Allow-Methods", strings.Join(m.config.AllowMethods, ", "))
            c.Header("Access-Control-Allow-Headers", strings.Join(m.config.AllowHeaders, ", "))
            
            if m.config.AllowCredentials {
                c.Header("Access-Control-Allow-Credentials", "true")
            }
        }
        
        // Handle preflight
        if c.Request.Method == "OPTIONS" {
            c.Status(204)
            return
        }
        
        c.Next()
    }
}
```

```go
                return true // Configure as needed

        if err != nil {
            return
        }

            hub:  g.hub,
            conn: conn,
            send: make(chan []byte, 256),

        go client.readPump()

        }
        
        switch msg.Type {
        case "message":
            response := []byte("Hello world!")
            c.send <- response
        case "events":
            // Handle events
        }
    }
```

```go
// @Accept json
// @Produce json

// @Failure 400 {object} ErrorResponse "Bad Request"

func (c *CatsController) Create(ctx *gin.Context) {
    var dto CreateCatDto
    if err := ctx.ShouldBindJSON(&dto); err != nil {
        ctx.JSON(400, ErrorResponse{Error: err.Error()})
        return

    cat := c.catsService.Create(dto)
    ctx.JSON(201, cat)
}
```

## Common Pitfalls

1. **Forgetting Pointer Types**: Always use pointer types for injected dependencies
2. **Route Registration**: Remember to include all routes in `GetRouteSpecs()`
3. **Middleware Order**: Middleware executes in order - auth should come before route handlers
4. **Context Values**: Use type assertions when retrieving values from Gin context
5. **Error Handling**: Go doesn't have exceptions - use error returns and panic recovery
6. **Async Operations**: Go uses goroutines instead of Promises/async-await
7. **Type Safety**: No runtime type checking - validate inputs manually
8. **Module Exports**: GIMBAP modules automatically expose providers to parent modules

## Summary

This guide covers the major patterns and features when porting NestJS applications to GIMBAP. The key differences are:

1. No decorators - use explicit registration
2. Manual parameter extraction from context
3. Engine-specific handler signatures
4. Pointer types for dependencies
5. Middleware-based request lifecycle
6. Struct tags for validation
7. No built-in ORM - use database/sql or third-party libraries

GIMBAP provides similar architectural benefits to NestJS while leveraging Go's strengths in performance and simplicity.
